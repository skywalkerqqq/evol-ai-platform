结构与结合预测

结构推理是异步任务：提交 → 排队 → 运行 → 落库，结果强制附带「镜像 digest + 权重 hash + 输入 hash」三要素。本机无 GPU，当前跑 mock 后端（确定性伪随机，同输入同输出），接上云 GPU 后切到真实 Boltz-2。
mock 后端
结构推理后端当前为确定性 mock，不是真实 Boltz-2 前向
真实接入需要：单卡 A100/A800（24–40 GB）· Boltz-2 权重（MIT）· 同源 MSA。后端接口已就位（engine/inference.py · BoltzBackend）， 接上算力后只需替换 ACTIVE_BACKEND 一处，任务队列、持久化、三要素落盘全都不动。 mock 的价值不在数字，在于把「提交 → 排队 → 复现」这条工程链路做真。
